# Skills

Claude Code skills. Each folder is one skill.

| Skill | What it does |
|---|---|
| [explainer-shorts](explainer-shorts/) | 32-38 s vertical English explainer Shorts/Reels with a free local pipeline, plus guidelines and lessons |

## Install a skill
Copy the skill's folder to `C:\Users\<you>\.claude\skills\` (macOS/Linux: `~/.claude/skills/`). `SKILL.md` must sit directly inside it, e.g. `.claude\skills\explainer-shorts\SKILL.md`. Then check with `/skills` in Claude Code.
